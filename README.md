# Fuzzy TV

Always-on music video channel: one video at a time, like old-school MTV minus the shows. Focused on newer, independent-ish rock artists.

Every viewer sees the same thing at the same moment. The playlist in `public/videos.json` loops starting at midnight Eastern time, and the page works out what's on from the clock.
